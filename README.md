🚀 **WhatsDesk** is an open-source WhatsApp marketing and automation platform designed to help businesses manage conversations, contacts, and campaigns efficiently.

This repository is the **community (open-source) edition** of [WhatsBox](https://codecanyon.net/item/whatsbox-the-whatsapp-marketing-bulk-sender-chat-bots-saas/48623156).  
---

## ✨ Features Included in Open Source Version

- ✅ WhatsApp Cloud API Integration  
- ✅ Message Sending (Text, Media, Templates)  
- ✅ WhatsApp Calls
- ✅ Contact Management  
- ✅ Basic Campaign Management  
- ✅ Webhook Handling  
- ✅ Multi-user Support  
- ✅ Analytics  
- ✅ API

---


## 🧰 Tech Stack

- **Backend:** Laravel  
- **Frontend:** Blade / React (depending on module)  
- **Database:** MySQL / PostgreSQL  
- **API:** WhatsApp Cloud API  
- **Queue:** Redis / Database  
- **Auth:** Laravel Authentication

## ⚙️ Local Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/mobidonia/whatsdesk.git
cd whatsdesk
```

### 2️⃣ Install dependencies
```
composer install
npm install
```

### 3️⃣ Environment setup
```
cp .env.example .env
```

### 4️⃣ Connect with Herd
Using [Herd](https://herd.laravel.com/), select the project.
Open your site at [whatsdesk.test](https://whatsdesk.test/)
